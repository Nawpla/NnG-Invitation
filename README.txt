Invitation Bundle - Nawfal and Ghian Sweet Eighteen

This folder contains everything needed to host your digital invitation.

Folders:
  index.html   the invitation page
  data/        event.json with your details
  css/         invitation styles
  js/          invitation script
  images/      photos you uploaded in the builder

How to deploy:
1. Upload this entire folder to any static web host.
2. Open index.html in your browser to preview.
3. To customize, edit data/event.json with your event details.

Keep the images/ folder next to index.html so uploaded photos keep working.

For more info: https://github.com/Rainier-PS/Invitation-Template
